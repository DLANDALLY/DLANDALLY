## 🚀 Featured Project

### 🤖 Simply Receipt

**AI-powered expense tracking through Telegram**

> Turn a receipt photo into structured financial data — automatically.

Simply Receipt combines messaging, OCR, AI and cloud infrastructure into an automated expense tracking workflow.

👉 **View project:**
https://github.com/DLANDALLY/SimplyReceiptBot

### ⚙️ How it works

* 📸 Send a receipt through Telegram
* 🔎 Extract information using Google Cloud Vision OCR
* 🧠 Structure and categorize data using Gemini AI
* ☁️ Process and deploy services on Google Cloud
* 📊 Store and export financial data
* ⚡ Automate the workflow from receipt to structured expense

### 🏗️ Engineering Focus
